# 🚀 Responsive Portfolio Landing Page

An interactive, mobile-friendly portfolio website developed during my **Frontend Development Internship** at **Think & Code Pvt Ltd**. Designed using modern web standards (**HTML5 & CSS3**), this project showcases web development skills, feature projects, and interactive UI components.

---

## 📸 Overview & Features

* **Header Navigation:** Adaptive navbar optimized for smooth browsing across all device sizes.
* **Hero Section:** Clean visual banner presenting an initial introduction and summary.
* **About Me:** Section detailing my background, aspirations, and experience.
* **Technical Skills:** Display of frontend capabilities and core competencies.
* **Featured Projects:** Interactive portfolio gallery linking directly to real estate project pages.
* **Contact Area:** Built-in contact form allowing visitors to send direct messages.
* **Footer:** Clean footer section containing social profiles and copyright information.
* **Adaptive Layouts:** Fully responsive structure built using custom media queries for screens of any size.

---

## 🛠️ Tech Stack & Concepts

| Technology / Method | Implementation Details |
| --- | --- |
| **HTML5** | Constructed using structural semantic markup (`<nav>`, `<main>`, `<section>`, `<footer>`) |
| **CSS3** | Custom styling, animations, and typography formatting |
| **Flexbox** | Aligned one-dimensional navigation bars, buttons, and content blocks |
| **CSS Grid** | Two-dimensional layouts for the project showcase and skills cards |
| **Media Queries** | Handcrafted breakpoints targeting handheld, tablet, and desktop viewports |
